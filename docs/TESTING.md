```sh
./gradlew --dependency-verification strict testDebugUnitTest
```

восстановление состояния, диапазоны, формат даты, интервал обновления,
високосные годы и укладка всех 119988 поддерживаемых месяцев в 42 ячейки.
Отчёт: `app/build/reports/tests/testDebugUnitTest/index.html`.

## UI smoke-тест

**Только одноразовый Android-эмулятор. Не ваш телефон.**

Нужны Python 3, ADB, установленный SDK и запущенный AVD с root-доступом.
Используйте AOSP-образ, без Google Play, например API 28 x86_64.

```sh
ADB=/path/to/sdk/platform-tools/adb python3 tests/ui_smoke.py \
  --serial emulator-5554 --apk /path/to/calendar.apk --out ui-test-output
```

Скрипт очищает данные приложения, устанавливает APK, меняет системные настройки
и намеренно записывает неверные типы SharedPreferences. Проверяет свайпы,
возврат к текущему месяцу, настройки, сохранение, поворот и восстановление.
Скриншоты нужно дополнительно просматривать глазами.

Он отказывается работать на физическом устройстве. Образ с запретом `adb root`
не подходит. После аварийного завершения могут остаться изменённые масштаб,
размер окна или настройки анимации — проще удалить одноразовый AVD.

## Что действительно проверялось

Для APK 1.2 ранее прошли unit-тесты, Lint, проверка подписи и UI smoke-тест
на Android 9 / API 28 x86_64. Отдельно проверялось соответствие сетки месяцу
после изменения размера окна и масштаба шрифта 200%.
Скриншоты в README — из этой сборки.

Это не означает тестирование на всех устройствах. Физический телефон,
все версии Android и особенности переноса данных разных OEM не покрыты.
Подготовка GitHub-репозитория не меняет код приложения и не является новым
прогоном APK на устройстве. Отдельные результаты GitHub Actions доступны во
вкладке Actions: там запускаются unit-тесты, Lint и сборка, но не UI smoke-тест.
