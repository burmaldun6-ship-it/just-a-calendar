# Изменения

## 1.2

- Стандартный ViewPager2 вместо самописного листания.
- Повторное использование страниц и более устойчивый возврат к сегодняшнему месяцу.
- Постоянные шесть строк сетки и неподвижный между месяцами блок «Сегодня».
- Шестерёнка с темой и настройкой обновления даты: 1–60 секунд, 5 по умолчанию,
  либо отключение таймера.
- Проверка восстановленного месяца и типов сохранённых настроек.
- Современные API настройки системных панелей.
- Явные исключения резервного копирования и переноса данных.
- Проверка SHA-256 Gradle и зависимостей, lockfile, unit-тесты.
- Исправление обрезания заголовка при крупном шрифте; удаление мёртвых ресурсов.

**Совместимость:** новый ключ подписи. Сначала удалите 1.1, затем установите 1.2.

## 1.1

- Центрированный заголовок месяца, листание свайпами без стрелок.
- Центрированный блок «Сегодня:» с датой `d.MM:yy`.
- Переключение светлой и тёмной тем.
